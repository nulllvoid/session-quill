Quickstart

From the marketplace command to a worker that starts at login, with the dashboard link in your status line. Nothing here needs a config file.

Prerequisites

  • Claude Code with plugin support.
  • Node.js 22 or newer on your PATH. It is not bundled with Claude Code.
  • Git, and a repository you work in. start requires a Git work tree.

Install the plugin

From the repository you want to track, inside Claude Code:

/plugin marketplace add nulllvoid/session-quill
/plugin install session-quill@session-quill

The same commands work from a terminal with claude plugin in place of /plugin. Start a new Claude session so the plugin loads.

Start tracking

/session-quill:start

Quill detects the repository, registers its main working tree privately, starts the background worker and captures the current session. No CLI alias, tracker connection, ticket or repository configuration file is required. A ticket key in your prompt or on your branch binds the session without a command.

A first setup uses ~/.claude/quill/store (or QUILL_HOME/store). To keep notes in a folder of your own, run /session-quill:start --store <folder> the first time. To write team defaults into a committable .quill.toml, add --share-settings.

Open the dashboard

/session-quill:ui

The dashboard runs on the loopback interface only. From 1.0 it listens on a stable port, 47321 by default, and falls back to a random port only when that one is taken. The command signs the browser in once; the session is stored as a hash with a sliding seven-day expiry, so a worker restart keeps you signed in. quill ui --revoke clears every session.

A request without a valid session gets a small page that says to run /session-quill:ui again. API requests keep JSON errors.

Start the worker at login

quill worker install

Registers a per-user login entry with no admin rights: a Task Scheduler logon task on Windows, a LaunchAgent on macOS, a systemd user unit on Linux. Installing twice leaves one entry; quill worker uninstall removes it and succeeds when it is already gone. quill doctor reports whether it is installed, and the dashboard's health popover shows Starts at login.

Restarts stay with the plugin's own backoff, not the OS keep-alive. A worker you stop with quill worker stop stays stopped until you run start again.

The status line link

Add the quill segment to your Claude Code status line in ~/.claude/settings.json:

{ "statusLine": { "type": "command", "command": "node /path/to/session-quill/scripts/statusline.js" } }

When the worker is healthy, the segment appends the dashboard URL as a terminal hyperlink. It prints nothing when the worker is down or its recorded pid is stale, and it never contains a secret.

Add a tracker

Optional. Put a [tracker] table in ~/.claude/quill/config.toml (just you) or the repository's .quill.toml (shared), name the token variable, and schedule a sync:

[tracker]
system          = "jira"                       # jira | github | linear
domain          = "https://example.atlassian.net"
sync_token_env  = "JIRA_TOKEN"                 # Jira Cloud also needs sync_username_env = "JIRA_EMAIL"
import_assigned = true                         # pull issues assigned to you into tickets
auto_clone_dir  = "~/src/quill"                # where consented clones land

[[schedule]]
name  = "tracker-sync"
job   = "tracker-sync"
every = "6h"

quill init --bootstrap-from-tracker turns on the import and runs one immediately, listing what came in. Tickets whose repository is known but not cloned show Needs clone; confirm the clone from the card or with quill repo clone KEY --confirm.

Make fixes test-verified

Give a repository a test command and the worker runs it after every attempt-fix run, in the run's worktree:

[repos.payments-api]
test_command    = "npm test"
test_timeout_ms = 600000

See the test gate for what happens on a failure.

Check that it works

quill doctor

Reports Node, Git and Claude versions, store ownership, the worker lock and heartbeat, ingress backlog, journal health, hook latency, capture gaps and ticket coverage for the last seven days. Logs live under ~/.claude/quill/logs/.
