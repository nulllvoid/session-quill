# Historical v0.1 diagrams

The PNG files in this directory were rendered from the original v0.1 design. They are retained as historical references and are not current implementation requirements.

The v0.2 architecture is in [TRD](../TRD.md#architecture), the screen map and layout in [UI-DESIGN](../UI-DESIGN.md#information-architecture), and release gates in [PRD](../PRD.md#release-plan). Use their inline Mermaid and tables. In particular, the old hosted-artifact architecture, stale status column and one-session release gates have been superseded.
