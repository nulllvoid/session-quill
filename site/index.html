A few things worth knowing.

Do I need Jira, Linear, or GitHub Issues?+

No. Internal tickets work locally with readable DEV, FEAT, and FIX keys. External trackers are optional and can be linked later.

Is a ticket the same as a session?+

No. A ticket represents a task. Multiple sessions can contribute to one task, and one session can switch between tasks. Previous activity keeps its original attribution.

What happens when I close Claude or reboot?+

Captured activity stays in local storage. The next Claude session can restart a missing worker. If you explicitly paused it, use /session-quill:start to resume.

Does it run background agents without permission?+

The local worker processes capture and scheduled jobs. Agent recipes have explicit read, edit, commit, push, and draft-PR permissions. A ticket binding is never permission to publish or deploy.
